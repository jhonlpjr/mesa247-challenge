Entregable 2 — Corte funcional

El corte funcional de Mesa247 Waiting List se encuentra disponible en el siguiente repositorio:

Repositorio: https://github.com/jhonlpjr/mesa247-challenge

La solución implementa el flujo principal solicitado:

Comensal se registra en la cola → anfitrión visualiza la cola → anfitrión llama al siguiente.

El proyecto incluye:

Backend desarrollado con FastAPI.
Frontend desarrollado con React + TypeScript.
Persistencia local con SQLite.
Migraciones y datos demo.
Pruebas automatizadas de los comportamientos principales.
Configuración y presets de despliegue.
Documentación técnica complementaria.

Las instrucciones completas para levantar y probar el proyecto se encuentran en el [README.md](../../README.md) principal del repositorio, incluyendo:

requisitos;
ejecución rápida;
URLs de acceso;
flujo de prueba paso a paso;
ejecución de tests;
configuración;
estructura y decisiones principales del proyecto.

El proyecto puede levantarse localmente siguiendo directamente la sección “Ejecución rápida” del [README.md](../../README.md).
