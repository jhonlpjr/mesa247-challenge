# Entregable 3 --- Conversaciones con IA

Durante la prueba técnica utilicé ChatGPT y Codex como apoyo para
análisis, toma de decisiones, implementación y revisión.

Las conversaciones se presentan separadas según las tres partes
solicitadas:

1.  `01-nota-tecnica.md`
2.  `02-backend.md`
3.  `03-frontend.md`

## Nota sobre el material incluido

Las conversaciones fueron recortadas únicamente para excluir contenido
previo no relacionado con la prueba técnica, navegación inicial, lectura
o reproducción del enunciado, metadatos de la herramienta y mensajes
administrativos o repetitivos que no aportan al proceso técnico.

Los intercambios incluidos relacionados con el análisis, toma de
decisiones, implementación y revisión de la prueba se mantienen en su
contenido original, sin reescrituras.

Cuando la copia disponible de una conversación contiene contenido
truncado por la propia interfaz (`…` o `Show more`), se conserva esa
limitación y no se reconstruye artificialmente.

Algunas sesiones abarcaron más de una capa. Para facilitar la revisión,
se clasificaron según el objetivo principal del intercambio.
